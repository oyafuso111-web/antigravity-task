# Antigravity Task – Gmail連携 Chrome拡張機能

GmailのWebUI上に「📋 タスク登録」ボタンを追加し、メールをワンクリックでAntigravity Taskに登録するChrome拡張機能です。

## 機能

- **ワンクリックでタスク登録**: Gmailでメールを開くと、件名の横に「📋 タスク登録」ボタンが表示されます
- **メール情報を自動取得**: 件名、送信者、日時、本文を自動的に取得してタスクに反映
- **タイトル編集可能**: 登録前にタスクのタイトルを編集できるミニモーダル
- **自動設定**: 期日は当日、タグに「メール」が自動設定されます
- **どのGmailアカウントでも動作**: 仕事用の別アカウントでもOK

## セットアップ手順

### 1. 拡張機能をChromeにインストール

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `chrome-extension` フォルダを選択

### 2. SupabaseにリダイレクトURLを追加

1. 拡張機能のアイコン（ツールバー）をクリックしてポップアップを開く
2. 表示されるリダイレクトURL（`https://xxxxx.chromiumapp.org/` の形式）をコピー
3. [Supabase Dashboard](https://supabase.com/dashboard) にアクセス
4. プロジェクト → **Authentication** → **URL Configuration**
5. **Redirect URLs** に、コピーしたURLを追加して保存

### 3. ログイン

1. 拡張機能のポップアップで「Googleでログイン」をクリック
2. **タスクアプリと同じGoogleアカウント** でログイン
3. ログイン完了後、ポップアップにユーザー情報が表示されます

## 使い方

1. GmailでメールをWebブラウザで開く（どのGmailアカウントでもOK）
2. メールの件名の横に表示される **「📋 タスク登録」** ボタンをクリック
3. ミニモーダルでタスクタイトルを確認・編集
4. **「登録する」** をクリック
5. ✅ トースト通知で登録完了を確認

タスクはAntigravity Taskアプリの **今日** のビューに表示されます（期日=本日、タグ=メール）。

## タスクに含まれる情報

| フィールド | 内容 |
|-----------|------|
| タイトル | メールの件名（編集可能） |
| 説明 | 送信者名、メールアドレス、日時、本文（先頭1000文字） |
| 期日 | 登録日（当日） |
| タグ | 「メール」（自動作成） |
| プロジェクト | なし（後からアプリで設定） |
| 優先度 | なし |

## トラブルシューティング

### ログインに失敗する
- SupabaseにリダイレクトURLが正しく追加されているか確認
- タスクアプリと同じGoogleアカウントでログインしているか確認

### ボタンが表示されない
- ページをリロードしてみてください
- Gmailの画面でメールを開いた状態（件名が表示されている状態）でのみボタンが表示されます

### タスクが登録できない
- 拡張機能のポップアップでログイン状態を確認
- Chrome DevToolsのConsoleにエラーが表示されていないか確認
